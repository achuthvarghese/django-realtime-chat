Groups and chat features

How group admins, live rooms, replies, reactions, mentions, the command palette and reading aids fit into the Signal chat screen. Numbered markers on the mockup match the UX changes table. Nothing is built yet.

Verified decisions

#TopicDecision
1Add people to a groupAny member
—Rename, remove members, delete groupAdmins only. The creator is admin by default; groups can have several admins; admins can make others admin or remove admin rights
2Last admin leavesLongest-standing member becomes admin automatically (system message). The last member leaving deletes the group
3Last admin demotionThe only admin cannot remove their own admin rights; they promote someone first, then step down. Members can never change admin rights
4Existing groupsMigration makes the earliest-added member the admin
5Hide direct chatslater kept on the list
6Seen byOn by default; Settings → Privacy toggle hides your receipts (and you then don't see others')
7Rate limitslater kept on the list
8Group colours8 preset colours, chosen by admins
9–10Notifications, searchHTTPS needed for notifications in production (documented); substring search for now
R1Theme controlSigned in: only in Settings → Appearance; the Theme button leaves the chat sidebar. Signed out (home, sign in, create account) keeps the Theme menu, since those pages can't reach Settings
R2UnmutingNo "unmute all". Settings lists muted chats with a checkbox each; Unmute selected is enabled only once at least one is ticked. The header bell still unmutes the open chat
R3UsernameVerified: Django's built-in user model with a unique username; signup collects and validates it, login authenticates by it. Gap: login is case-sensitive while signup treats usernames case-insensitively. Fix proposed as P9-pre below

UX changes these features need

Adding six features to one screen would crowd it. These adjustments keep the one-line transcript intact.

Account: username rules, account menu, settings sections

Username rules (signup)

RuleValidRejected
Uniquemaya_raomaya_rao if taken
Lowercase letters, digits and _ onlylee2Lee, lee.chen, lee-chen
_ stands in for spacesanika_shahanika shah
No two _ in a rowa_b_ca__b
Can't start or end with _sam_2_sam, sam_
3–30 characters, starts with a letterlee, maya_rao2al, 2fast
Existing accountsRenamed by a migration to the new format; clashes get _2, _3…; the migration prints old → new names

While you type, the field formats for you: capitals become lowercase and spaces become a single _; other characters show an inline error. A hint under the field states the rules. Sign-in accepts any letter case. All rules confirmed.
